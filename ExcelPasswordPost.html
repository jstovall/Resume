How to Unlock a Password-Protected Excel Sheet (Without the Password)

Let's say a former coworker left. The password left with them. The spreadsheet did not.

It happens more often than anyone cares to admit. Someone builds an elaborate Excel workbook, locks it down to protect their formulas or formatting, and then moves on to greener pastures — taking the password with them. Now it's yours to deal with.

Good news: if the file opens fine but the sheets are locked for editing, you can fix this yourself in about ten minutes. No special software required. Just Python, which is free.

First: Which Kind of Protection Do You Have?

Excel has two very different types of password protection, and only one of them is beatable:

✅ Sheet protection — the file opens normally, but you get a message like "The cell or chart you're trying to change is on a protected sheet" when you try to edit. This guide handles this.
🔒 Workbook open password — Excel asks for a password before the file opens at all. This uses real encryption. Not fixable without the password. Time to call IT.

Still with me? Great. Let's get into it.

Why This Works

An .xlsx file is secretly just a ZIP archive full of XML files. The "protection" is a single XML tag inside one of those files — sometimes just a hash, sometimes nothing more than a flag. We're going to open the ZIP, surgically remove those tags, and put it back together. Excel will be none the wiser.

The old approach was to rename the file from .xlsx to .zip, dig around manually, and delete the tags by hand. It works, but it's fiddly — especially if there are many sheets, or if the protection uses a stronger SHA-512 hash format (which the manual find-and-replace tends to miss). The Python script below handles all of that automatically.

What You'll Need

  • Python 3 — python.org. During install, check "Add Python to PATH" or you'll have a bad time.
  • A text editor — VS Code is great, but Notepad works too in a pinch.
  • The Excel file — make a backup copy first. Seriously. Takes two seconds.

The Script

Create a new file called unlock_excel.py, paste in the code below, and update the filename on line 3 to match your file:

import zipfile, shutil, re

input_file  = "your_file.xlsx"   # ← change this
output_file = "unlocked.xlsx"

with zipfile.ZipFile(input_file, 'r') as zin:
    with zipfile.ZipFile(output_file, 'w', zipfile.ZIP_DEFLATED) as zout:
        for item in zin.infolist():
            data = zin.read(item.filename)

            # Remove sheet-level protection
            if item.filename.startswith('xl/worksheets/sheet'):
                data = re.sub(rb'<sheetProtection[^>]*/>', b'', data)

            # Remove workbook-level protection
            if item.filename == 'xl/workbook.xml':
                data = re.sub(rb'<workbookProtection[^>]*/>', b'', data)

            zout.writestr(item, data)

print("Done! Saved as", output_file)

Save unlock_excel.py in the same folder as your Excel file. Then open a terminal (in VS Code: Terminal → New Terminal), and run:

python unlock_excel.py

You should see Done! Saved as unlocked.xlsx. Open that file and you're in.

If It Didn't Work

Sheets still locked? Delete unlocked.xlsx and try again — make sure you opened the new file, not the original. Also double-check the filename in the script matches exactly, including the .xlsx extension.
"python" not found? Python probably isn't on your PATH. Try python3 instead. If that fails too, reinstall Python and make sure you check "Add to PATH" during setup.
The file asks for a password just to open? That's workbook encryption — a fundamentally different thing. This script won't help. You'll need the original password or a dedicated recovery tool, and even then it's not guaranteed.

A Note on When to Use This

This is a legitimate tool for legitimate situations. The most common ones:

A former employee left and took the password with them
Someone protected a file "just in case" and forgot the password years ago
You inherited a file with no documentation whatsoever -- just typical
You need to update a template that's been locked since 2014
The spreasheet sirens are singing and there's no turning back now!

Disclaimer: You should not use this to access files you're not supposed to touch. I have to say that ;)

That's it. Ten minutes, a few lines of Python, and one less thing standing between you and your spreadsheet.
